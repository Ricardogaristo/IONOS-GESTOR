Gestor Garisto — Gestor de Tareas
Aplicación web interna desarrollada en Python / Flask para la gestión de tareas, formación y usuarios dentro del equipo.
  • Panel de tareas con filtros, estados y asignaciones
  • Dashboard con métricas y progreso
  • Módulo de formación SCORM integrado
  • Control de acceso por roles (usuario / admin / superadmin)
  • Tema claro/oscuro persistente
